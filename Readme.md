SEMANA 1 - ALGORITMOS SECUENCIALES

Ejercicios basados en instrucciones secuenciales, entrada de datos, operaciones y presentación de resultados.

Cada ejercicio contiene su código fuente, diagrama de flujo y pruebas con diferentes entradas.

SEMANA 2 - ALGORITMOS DE DECISIÓN

Ejercicios que implementan estructuras condicionales para evaluar situaciones y tomar decisiones.

Cada ejercicio contiene el código fuente, explicación de las condiciones utilizadas, tabla de decisión y pruebas de escritorio con casos normales y casos límite.

SEMANA 3 - CICLOS Y SUBPROCESOS

Ejercicios que implementan estructuras repetitivas y descomposición modular de algoritmos.

Cada ejercicio contiene el código fuente, explicación de la lógica del ciclo utilizado, tabla de traza y pruebas de escritorio.

La factura está organizada mediante los siguientes subprocesos:

CalcularSubtotal: realiza la suma de los valores parciales.

MostrarDetalle: presenta los productos y sus respectivos valores.

MostrarTotales: muestra el subtotal, el IVA y el total de la factura.

También se incluye el árbol de componentes que representa la estructura modular del algoritmo.
